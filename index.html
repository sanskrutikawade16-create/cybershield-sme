01 • FRAMEWORK

NIST-inspired five-function model

The prototype maps SME security activities to the five core NIST Cybersecurity Framework functions.

01

Identify

Inventory assets, data, users, suppliers, and business-critical services.

02

Protect

Apply MFA, secure configuration, backups, access control, and training.

03

Detect

Monitor suspicious activity, endpoint alerts, logs, and account anomalies.

04

Respond

Contain incidents, communicate responsibilities, and preserve evidence.

05

Recover

Restore trusted systems, test backups, and improve the response plan.
